# 方大同音乐旅程｜粉丝致敬页面

一个以中文呈现的方大同粉丝致敬单页，串联音乐人介绍、十张专辑、影像记忆与公益主题内容，供读者浏览他的音乐旅程。

## 页面内容

- **音乐人介绍**：以文字介绍方大同的音乐风格与创作形象，并列出 Soul、R&B、Neo-Soul、Jazz 等标签。
- **专辑旅程**：横向滑动浏览页面列出的十张专辑，包含封面、年份、名称和简短介绍。
- **影像记忆**：以网格展示仓库中的演出、生活照片及专辑拼贴、手绘素材。
- **公益主题**：以年份时间线呈现页面收录的公益相关内容。

## 界面与交互

页面采用暖白、米色与棕色为主的视觉配色，搭配衬线字体、专辑卡片和图片网格。顶部导航链接到页面各区块；首屏按钮跳转至专辑区；专辑列表支持横向滚动，时间线项目在进入视口时显示动画。样式中包含平板、手机断点及减少动态效果的偏好设置。

## 技术与素材

- 原生 HTML、CSS 与浏览器端 JavaScript，集中在 `index.html` 中；没有项目包管理清单或构建配置。
- 图片素材位于 `assets/covers/` 与 `assets/photos/`。
- 页面从 Google Fonts 加载 Noto Serif SC 与 Playfair Display；离线或无法访问 Google Fonts 时会回退到系统字体。

## 本地预览

无需安装项目依赖或构建。可在仓库根目录运行一个静态 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。也可以直接打开 `index.html`；使用 HTTP 服务通常更接近常规网页预览方式。
